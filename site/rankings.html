About these rankings

This page lists journal grades from the CABS Academic Journal Guide, as published in the Editor-Collector freeze rankings_abs_ajg_20261024. It is a separate page from the editor directory. FT50, ABDC, Top 5, and UTD24 chips on that directory are unchanged. ABS/AJG is not a directory chip.

Editions on file are 2010, 2015, 2018, 2021, and 2024. AJG 2024 has 1,823 journals, of which 1,378 (75.6%) have a catalog journal_id. Across all five editions, 1,478 of 7,245 rows are unmatched. The files are under journals/rankings/abs_ajg/releases/rankings_abs_ajg_20261024/.

journal_id is the freeze’s primary catalog id. A blank cell is an unmatched title, listed in unmatched_journals.csv.

More ranking systems can be added later under journals/rankings/. Build locally with python scripts/build_site.py. The project site is kochiuyu.github.io/econ-journal-dispersion.
