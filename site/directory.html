    Current FT50, ABDC, and AJG-gap journal editors

    About this directory

    This is the public editor list for Geographic Dispersion / econ-journal-dispersion. It is built from the analysis releases under data/editors/*/releases/current/, not from a live scrape of this repository. The FT50 file is the ROR-enriched current board. ABDC is the 2025 Journal Quality List at A*, A, B, and C. AJG-gap is the current boards in data/editors/abs_ajg_gap/releases/current/: journals in the 2024 guide that are not already in the FT50 or ABDC editor files. Names and affiliations are freeze editors_institution_problem_list_20261028 on FT50, ABDC A*, A, B, and C, and the AJG-gap boards. Faculty URLs from the earlier URL freezes stay on rows this freeze did not replace. African Affairs is the 2024-04-27 Wayback board. A blank editor_name is not listed. A blank affiliation is not an institution, and a bare country is not an institution. Top 5 and UTD24 are tags on the FT50 and ABDC releases, read from journals/catalog_top5.csv and journals/catalog_utd24.csv. AJG grades on those releases are read from the 2024 edition in journals/rankings/abs_ajg/releases/rankings_abs_ajg_20261024/ and its crosswalk. That id join does not add a board for FT50 or ABDC rows. Gap rows take the grade from the panel that supplied the board. core49 is an older ABDC A* subset and is not a separate list here. Authors are not in this version.

    Board year 2026. Counts above are appointments (one person, in one role, on one journal), distinct names, journals, and countries with a matched institution. Two people whose names fold to the same string are counted once. Different spellings are counted twice.

    How lists load

    Opening this page downloads FT50 only. Choosing another list downloads that list’s appointments and leaves the page shell in place while the file arrives. Top 5 is inside FT50, so that chip does not need a second download after FT50 has loaded. Search and the role, field, country, and institution filters apply to lists that are already loaded. A journal name on the Journals page opens this directory on that journal and loads a list that contains it, without forcing FT50. An institution name on the Institutions page loads the lists needed for that affiliation. Older links to the site root with a directory query, or to #directory, land here. ?u= names the lists. u=- selects none.

    How overlap is shown

    Where the same person, journal, and role appear in both the FT50 release and an ABDC rating, the table shows one row and both badges. The wording comes from the FT50 file. A missing affiliation or country is filled from the ABDC row. A different role, or the same role on another journal, stays a separate row. The same name and role on one journal with two different affiliations is kept as two rows. The role filter groups masthead titles (Editor-in-Chief, Editor, Co-Editor, Senior Editor, Managing Editor, Associate Editor, Guest / Special Issue Editor, Editorial Board, Review Board, Advisory Board, and Other). The Role column is the journal’s own title.

    Top 5 and UTD24

    Top 5 is American Economic Review, Econometrica, Journal of Political Economy, Quarterly Journal of Economics, and Review of Economic Studies. Each of those appointments also carries the FT50 badge. UTD24 is the UT Dallas Naveen Jindal list of 24 business journals. Twenty-three of them are in the FT50 release. INFORMS Journal on Computing, listed by UTD as Journal on Computing, is included from the ABDC A release so the chip covers the full list. Journal of Applied Psychology remains an FT50 appointment and does not carry a UTD24 badge.

    AJG grades

    AJG chips are grades on the boards in this directory. The list chip and the row badge both show one grade: AJG 4*, AJG 4, AJG 3, AJG 2, or AJG 1. On FT50 and ABDC rows the grade comes from rating on the 2024 edition, the latest edition in journals/rankings/abs_ajg/releases/rankings_abs_ajg_20261024/. The id join uses abs_ajg_2024.csv and the 2024 rows of journal_id_crosswalk.csv, so a journal whose primary id is a core49 slug still matches the ABDC id on the board file. The Economic Journal is one of those, and its badge is AJG 4. Titles that join left unmatched stay untagged on those boards. Accounting Educators Journal stays an ABDC journal without an AJG badge.

    That edition has 1,823 journals. 1,378 map to a catalog id, and about 1,356 of those sit on a current FT50 or ABDC board and show a chip from the id join. The 445 unmatched titles have no catalog id, so that join does not tag them. Many ABDC board journals have no AJG grade: about 2,400 ABDC board journal ids, against about 1,356 with an AJG hit. AJG-gap rows are extra boards for journals not already in those editor files. The priority file allows grades 4*, 4, and 3; in this freeze those rows are AJG 4 and AJG 3, because every 4* title is already on an FT50 or ABDC board. The other two files are AJG 2 and AJG 1. A gap row carries that AJG grade. FT50 and ABDC badges stay on appointments from those releases. The directory shows a chip on 1,796 journals: every 4*, 4, and 3 title, and most 2 and 1 titles. 27 titles still have no board. Earlier editions, and titles with no board, stay on the Rankings page. ABDC labels are unchanged.

    Institution and field

    Institution is the affiliation stored on the row: the matched ROR name when the release has one, otherwise the canonical or masthead affiliation. Suggestions come from the lists loaded so far, so the page does not scan every appointment to build a menu. Choosing one keeps appointments with that exact affiliation. The Institutions page links here with that name and loads the lists that contain it. Field is field_for from the 2025 ABDC catalogs, the same subject as the Field filter on Journals. The menu shows the subject name for journals in the loaded lists. The code stays on the cell title.

    Country and continent are the ROR fields on the release. Affiliations prefer the matched institution name. Emails, phone numbers, and photos are not published; contact strings found in a masthead field are removed. Journal names link to the public board page when source_url is an http(s) URL. Some AJG-gap journals in this freeze have no public board URL, so the name stays plain text. A name links to a faculty profile when faculty_profile_url is filled. AJG-gap coverage is partial (1,084 of 19,303 rows), so a gap name with no profile stays plain text. Coverage on the other releases is partial: higher on FT50 and ABDC A* than on B and C, so a name with no profile stays plain text. The directory does not link faculty_home_page, and it does not invent ORCID, OpenAlex, or RePEc person links.

    Journals is one row per journal. Institutions is one row per institution, using the ROR id when the release has one. A bare country, a bracket-only fragment, or a street, PO Box, or postal code with no organization name is not a row. A journal name opens this directory on that journal. An institution name opens it on that affiliation and country.

    CNRS, Handelsblatt/VWL, FNEGE, Tilburg, ERIM, Stern, Shanghai, and SHUFE grades, the earlier ABS/AJG editions, the 2025 ABDC ratings, and FT50, UTD24, and Top 5 membership lists are on the Rankings page. Those rows are journal grades, not editorial appointments. The AJG chips on this directory are the 2024 grades on a current FT50, ABDC, or AJG-gap board.
