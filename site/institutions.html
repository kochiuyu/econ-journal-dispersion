About this institution list

Each row is one institution among the appointments in the editor directory. The build groups on ror_id when the collapsed row has one. Otherwise it groups on the affiliation name, with case and extra spaces ignored. The name in the table is the wording that appears most often for that key. Country and continent are the most common ROR values on those appointments.

Appointments with no named institution are omitted. Opening a name filters the directory to that affiliation and, when the row has one, that country. A person counted at two institutions is two appointments. The same person on two journals at one institution is one editor and two appointments. Emails, phone numbers, and photos are not published.

Board year 2026. Journals are on the Journals page. The AJG chips are 2024 CABS grades (AJG 4*, AJG 4, AJG 3, AJG 2, and AJG 1) on journals that have one, including AJG-gap boards. Selecting one does not invent FT50 or ABDC boards, and many ABDC journals have no grade. AJG-gap rows group on ror_id when that cell is filled. Those boards are freeze editors_institution_residual_post35_20261028. A residual place inside the institution name is stripped, and a country mismatch is corrected. The table uses the ROR name and country. A country suffix on the masthead collapses into that row when the id matches. A row with an empty editor_name is not a person in the directory. When that row has a ror_id, it still counts as an appointment here and does not count as an editor. Appointments that still have no ROR id stay grouped on the affiliation string, except a blank affiliation, a bare country or territory, a string fully enclosed in brackets, or a street, PO Box, or postal code with no organization name. 11KBW, UNSW Sydney, and INSEAD stay. The masthead text stays raw_affiliation on the release. Titles with no board, and earlier editions, stay on Rankings.

Build locally with python scripts/build_site.py. The project site is kochiuyu.github.io/econ-journal-dispersion.
